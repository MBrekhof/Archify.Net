# Archify.Net Phase 6 — MCP Server + Skill Wrapper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the stdio MCP server (`src/Archify.Net.Mcp`, tool command `archify-mcp`) exposing the 4 Phase 6 tools (`archify_validate`, `archify_render`, `archify_finalize`, `archify_guide`), the self-contained agent skill package (`skill/archify/SKILL.md` + `references/` + `schemas/` + `examples/`), end-to-end MCP protocol and Chromium tests (`tests/Archify.Net.Mcp.Tests`), final project documentation (`README.md`, `SESSION_HANDOFF.md`), and the Claude Code exit demonstration for `Archify.Net`.

**Architecture:** `Archify.Net.Mcp` is a thin stdio Model Context Protocol host built on the official C# `ModelContextProtocol` (`2.2.0`) NuGet package. It references `Archify.Net.Cli` (which transitively references `Archify.Net.Core`) and dispatches each of its 4 MCP tools (`archify_validate`, `archify_render`, `archify_finalize`, `archify_guide`) in-process through `Archify.Net.Cli.Cli.Run(string[] argv, CliIo io)` via `Task.Run` under a server-wide `SemaphoreSlim(1, 1)` execution lock. Tool methods return `CallToolResult` directly so CLI exit code `0` maps to `IsError = false` (returning the CLI's stdout verbatim) and CLI exit codes `1` and `2` map to `IsError = true` with the full JSON receipt or diagnostic text preserved in `TextContentBlock` for agent self-repair. `Archify.Net.Core` and `Archify.Net.Cli` retain their existing dependencies untouched.

**Tech Stack:** .NET 10 (`net10.0`, C# 13), `ModelContextProtocol` `2.2.0`, `System.IO.Pipelines`, `System.Text.Json`, xUnit v2 (`2.9.3`).

**Spec reference:** `docs/superpowers/specs/2026-10-13-archify-csharp-port-design.md` (`## MCP server + skill (phase 6)`).

4. **Code reuse, concurrency & async execution:** `Archify.Net.Mcp` invokes `Archify.Net.Cli.Cli.Run([.. argv], io)` in-process using a per-call `CliIo` (`StringWriter` stdout/stderr, explicit `Cwd`, and injected `CliServices`) guarded by a `SemaphoreSlim(1, 1)`. Inside the semaphore, `ExecuteCliAsync` honours `CancellationToken` before starting and runs `Archify.Net.Cli.Cli.Run` via `Task.Run(..., cancellationToken)` so long synchronous runs (such as Chromium-backed `finalize`) do not block the MCP message loop.
5. **Error & receipt mapping:** `Cli.Run` exit code `0` maps to `CallToolResult { IsError = false, Content = [new TextContentBlock { Text = outText }] }`. Exit codes `1` (gate/validation failure) and `2` (argument refusal or browser unavailable / `status: "skipped"`) map to `CallToolResult { IsError = true, Content = [new TextContentBlock { Text = errorPayload }] }` where `errorPayload` is the JSON receipt on `stdout` (or `stderr` diagnostic text when `stdout` is empty), never a JSON-RPC protocol exception.
6. **Working directory (`cwd`) & path resolution:** Every file-taking MCP tool (`archify_validate`, `archify_render`, `archify_finalize`) accepts an optional `cwd` (`string? = null`) parameter. When `cwd` is provided, `ArchifyTools` verifies that the directory exists (returning `IsError = true` with a structured `input/cwd-invalid` JSON error if invalid or missing) and passes `Path.GetFullPath(cwd)` as `CliIo.Cwd`; when omitted, `CliIo.Cwd` defaults to `_defaultCwd` (`Directory.GetCurrentDirectory()`).

```csharp
using System.Reflection;
using ModelContextProtocol.Protocol;
using ModelContextProtocol.Server;

namespace Archify.Net.Mcp;

public static class ArchifyMcpServer
{
    public const string ServerName = "archify-mcp";
    public const string ServerVersion = "1.0.0";

    public const string Instructions =
        "Archify MCP server for recommending, validating, rendering, and finalizing interactive HTML diagrams. " +
        "Use archify_guide to recommend a diagram type for a plain-language scenario, archify_validate to validate " +
        "or inspect layout geometry, archify_render to render standalone HTML, and archify_finalize to run the full " +
        "delivery, artifact check, and headless browser verification gates.";

    public static McpServerOptions CreateOptions(ArchifyTools tools)
    {
        ArgumentNullException.ThrowIfNull(tools);

        var toolCollection = new McpServerPrimitiveCollection<McpServerTool>();
        var methods = typeof(ArchifyTools).GetMethods(BindingFlags.Public | BindingFlags.Instance);
        foreach (var method in methods)
        {
            if (method.GetCustomAttribute<McpServerToolAttribute>() is not null)
            {
                toolCollection.Add(McpServerTool.Create(method, tools));
            }
        }

        return new McpServerOptions
        {
            ServerInfo = new Implementation
            {
                Name = ServerName,
                Version = ServerVersion,
            },
            ServerInstructions = Instructions,
            ToolCollection = toolCollection,
        };
    }

    public static McpServer CreateServer(ITransport transport, ArchifyTools tools)
    {
        ArgumentNullException.ThrowIfNull(transport);
        ArgumentNullException.ThrowIfNull(tools);
        var options = CreateOptions(tools);
        return McpServer.Create(transport, options);
    }

    public static async Task<int> RunStdioAsync(string[] args, TextWriter stdout, TextWriter stderr, CancellationToken cancellationToken = default)
    {
        ArgumentNullException.ThrowIfNull(args);
        ArgumentNullException.ThrowIfNull(stdout);
        ArgumentNullException.ThrowIfNull(stderr);

        if (args.Length == 1 && (args[0] == "--version" || args[0] == "-v"))
        {
            await stdout.WriteLineAsync(ServerVersion).ConfigureAwait(false);
            return 0;
        }

        if (args.Length == 1 && (args[0] == "--help" || args[0] == "-h"))
        {
            await stdout.WriteLineAsync("Usage: archify-mcp [--version] [--help]").ConfigureAwait(false);
            await stdout.WriteLineAsync("Runs the Archify Model Context Protocol (MCP) server over stdio.").ConfigureAwait(false);
            return 0;
        }

        if (args.Length > 0)
        {
            await stderr.WriteLineAsync($"archify-mcp: unknown argument '{args[0]}'. Expected no arguments, --version, or --help.").ConfigureAwait(false);
            return 2;
        }

        using var tools = new ArchifyTools();
        var options = CreateOptions(tools);
        await using var transport = new StdioServerTransport(options);
        await using var server = McpServer.Create(transport, options);
        await server.RunAsync(cancellationToken).ConfigureAwait(false);
        return 0;
    }
}
```

```csharp
using System.ComponentModel;
using System.Globalization;
using System.Text;
using System.Text.Json;
using Archify.Net.Cli;
using ModelContextProtocol.Protocol;
using ModelContextProtocol.Server;

namespace Archify.Net.Mcp;

[McpServerToolType]
public sealed class ArchifyTools : IDisposable
{
    private readonly SemaphoreSlim _gate = new(1, 1);
    private readonly string _defaultCwd;
    private readonly CliServices _services;

    public ArchifyTools(string? defaultCwd = null, CliServices? services = null)
    {
        _defaultCwd = string.IsNullOrWhiteSpace(defaultCwd)
            ? Directory.GetCurrentDirectory()
            : Path.GetFullPath(defaultCwd);
        _services = services ?? CliServices.Default;
    }

    public string DefaultCwd => _defaultCwd;

    [McpServerTool(
        Name = "archify_guide",
        Title = "Archify Scenario Guide",
        ReadOnly = true,
        Idempotent = true,
        Destructive = false,
        OpenWorld = false)]
    [Description("Recommend an Archify diagram type and scenario recipe for a plain-language scenario or question, or list all scenario recipes when query is omitted.")]
    public Task<CallToolResult> GuideAsync(
        [Description("Optional scenario or question in plain language (for example, 'approval gate for leave requests' or 'Show an API request with Redis cache miss'). Omit to list all scenario recipes.")]
        string? query = null,
        [Description("Optional output language: 'en' or 'zh'. When omitted, detected from query or defaults to 'en'.")]
        string? lang = null,
        CancellationToken cancellationToken = default)
    {
        var argv = new List<string> { "guide" };
        if (!string.IsNullOrWhiteSpace(query))
        {
            argv.Add(query.Trim());
        }

        argv.Add("--json");
        if (!string.IsNullOrWhiteSpace(lang))
        {
            argv.Add("--lang");
            argv.Add(lang.Trim());
        }

        return ExecuteCliAsync(argv, cwd: null, cancellationToken);
    }

    internal async Task<CallToolResult> ExecuteCliAsync(
        IReadOnlyList<string> argv,
        string? cwd,
        CancellationToken cancellationToken)
    {
        cancellationToken.ThrowIfCancellationRequested();

        string effectiveCwd;
        if (!string.IsNullOrWhiteSpace(cwd))
        {
            try
            {
                effectiveCwd = Path.GetFullPath(cwd);
            }
            catch (Exception ex) when (ex is ArgumentException or NotSupportedException or PathTooLongException)
            {
                return CreateErrorResult(BuildCwdErrorJson(cwd, ex.Message));
            }

            if (!Directory.Exists(effectiveCwd))
            {
                return CreateErrorResult(BuildCwdErrorJson(cwd, $"Working directory does not exist: {effectiveCwd}"));
            }
        }
        else
        {
            effectiveCwd = _defaultCwd;
        }

        await _gate.WaitAsync(cancellationToken).ConfigureAwait(false);
        try
        {
            cancellationToken.ThrowIfCancellationRequested();

            var stdoutBuilder = new StringBuilder();
            var stderrBuilder = new StringBuilder();
            int exitCode;
            await using (var stdout = new StringWriter(stdoutBuilder, CultureInfo.InvariantCulture) { NewLine = "\n" })
            await using (var stderr = new StringWriter(stderrBuilder, CultureInfo.InvariantCulture) { NewLine = "\n" })
            {
                var io = new CliIo(stdout, stderr, effectiveCwd, _services);
                var argsArray = argv.ToArray();
                exitCode = await Task.Run(() => Archify.Net.Cli.Cli.Run(argsArray, io), cancellationToken).ConfigureAwait(false);
            }

            var outText = stdoutBuilder.ToString().TrimEnd('\r', '\n');
            var errText = stderrBuilder.ToString().TrimEnd('\r', '\n');

            if (exitCode == 0)
            {
                return new CallToolResult
                {
                    IsError = false,
                    Content = [new TextContentBlock { Text = outText }],
                };
            }

            var errorPayload = !string.IsNullOrWhiteSpace(outText)
                ? outText
                : (!string.IsNullOrWhiteSpace(errText) ? errText : $"Command '{string.Join(' ', argv)}' exited with code {exitCode}.");

            return CreateErrorResult(errorPayload);
        }
        finally
        {
            _gate.Release();
        }
    }

    private static CallToolResult CreateErrorResult(string text) =>
        new()
        {
            IsError = true,
            Content = [new TextContentBlock { Text = text }],
        };

    private static string BuildCwdErrorJson(string rawCwd, string message)
    {
        using var stream = new MemoryStream();
        using (var writer = new Utf8JsonWriter(stream))
        {
            writer.WriteStartObject();
            writer.WriteBoolean("ok", false);
            writer.WriteString("stage", "input");
            writer.WriteString("error", message);
            writer.WriteStartArray("diagnostics");
            writer.WriteStartObject();
            writer.WriteString("code", "input/cwd-invalid");
            writer.WriteString("severity", "error");
            writer.WriteStartObject("subject");
            writer.WriteString("cwd", rawCwd);
            writer.WriteEndObject();
            writer.WriteString("message", message);
            writer.WriteEndObject();
            writer.WriteEndArray();
```

```csharp
    internal async Task<CallToolResult> ExecuteCliAsync(
        IReadOnlyList<string> argv,
        string? cwd,
        CancellationToken cancellationToken)
    {
        cancellationToken.ThrowIfCancellationRequested();

        string effectiveCwd;
        if (!string.IsNullOrWhiteSpace(cwd))
        {
            try
            {
                effectiveCwd = Path.GetFullPath(cwd);
            }
            catch (Exception ex) when (ex is ArgumentException or NotSupportedException or PathTooLongException)
            {
                return CreateErrorResult(BuildCwdErrorJson(cwd, ex.Message));
            }

            if (!Directory.Exists(effectiveCwd))
            {
                return CreateErrorResult(BuildCwdErrorJson(cwd, $"Working directory does not exist: {effectiveCwd}"));
            }
        }
        else
        {
            effectiveCwd = _defaultCwd;
        }

        await _gate.WaitAsync(cancellationToken).ConfigureAwait(false);
        try
        {
            cancellationToken.ThrowIfCancellationRequested();

            var stdoutBuilder = new StringBuilder();
            var stderrBuilder = new StringBuilder();
            int exitCode;
            await using (var stdout = new StringWriter(stdoutBuilder, CultureInfo.InvariantCulture) { NewLine = "\n" })
            await using (var stderr = new StringWriter(stderrBuilder, CultureInfo.InvariantCulture) { NewLine = "\n" })
            {
                var io = new CliIo(stdout, stderr, effectiveCwd, _services);
                var argsArray = argv.ToArray();
                exitCode = await Task.Run(() => Archify.Net.Cli.Cli.Run(argsArray, io), cancellationToken).ConfigureAwait(false);
            }

            var outText = stdoutBuilder.ToString().TrimEnd('\r', '\n');
            var errText = stderrBuilder.ToString().TrimEnd('\r', '\n');

            if (exitCode == 0)
            {
                return new CallToolResult
                {
                    IsError = false,
                    Content = [new TextContentBlock { Text = outText }],
                };
            }

            var errorPayload = !string.IsNullOrWhiteSpace(outText)
                ? outText
                : (!string.IsNullOrWhiteSpace(errText) ? errText : $"Command '{string.Join(' ', argv)}' exited with code {exitCode}.");

            return CreateErrorResult(errorPayload);
        }
        finally
        {
            _gate.Release();
        }
    }

    private static CallToolResult CreateErrorResult(string text) =>
        new()
        {
            IsError = true,
            Content = [new TextContentBlock { Text = text }],
        };

    private static string BuildCwdErrorJson(string rawCwd, string message)
    {
        using var stream = new MemoryStream();
        using (var writer = new Utf8JsonWriter(stream))
        {
            writer.WriteStartObject();
            writer.WriteBoolean("ok", false);
            writer.WriteString("stage", "input");
            writer.WriteString("error", message);
            writer.WriteStartArray("diagnostics");
            writer.WriteStartObject();
            writer.WriteString("code", "input/cwd-invalid");
            writer.WriteString("severity", "error");
            writer.WriteStartObject("subject");
            writer.WriteString("cwd", rawCwd);
            writer.WriteEndObject();
            writer.WriteString("message", message);
            writer.WriteEndObject();
            writer.WriteEndArray();
            writer.WriteEndObject();
        }

        return Encoding.UTF8.GetString(stream.ToArray());
    }

    {
        _gate.Dispose();
    }
}
```
